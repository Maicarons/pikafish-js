首个可用版本：官方 Pikafish 引擎编译为 WebAssembly，在浏览器里完成人机对弈与本地分析。

- 上游 Pikafish：`545c4e3b251afbb94f493c6c5f32549f900e76fd`
- Emscripten：`3.1.74`
- NNUE：`master-net` / `pikafish.nnue`，50,241,100 B
  SHA-256 `bf3982711150bf2f8b49e99cd93421320f6ca914cfcf131dad5eb7f2402573ac`
- 许可：AGPL-3.0-or-later

## 新增

### 引擎包 `pikafish-js`

- `createEngine()`：创建 classic Worker、加载 wasm、写入权重、完成 `uci`/`isready` 握手
- 三套构建：`threads-simd`（多线程 + SIMD）、`single-simd`、`single-nosimd`
- `analyze()` 流式搜索（`AsyncIterable<AnalysisInfo>`）与 `play()` 一次性搜索
- 权重双分发：`netUrl`（Cache Storage + SHA-256 校验 + 损坏自愈）或 `netData`
- `setOption` / `stop` / `dispose`，事件 `ready`、`info`、`bestmove`、`degraded`、`error` 等
- 错误码覆盖环境、资源、网络、哈希、初始化与搜索中止

### 规则包 `@pikafish-js/rules`

- FEN 解析与序列化（rank 0 = 红方底线，与 UCCI 一致）
- 完整走子生成，含马腿、塞象眼、炮架、九宫限制、将帅照面、送将过滤
- `Game`：落子、悔棋、认输、状态缓存、重复局面计数
- 裁决：将死、困毙判负、三次重复（长将判负，其余判和）、120 半回合、子力不足
- 中文记谱（`炮二平五`）与 `+`/`#` 后缀

### 演示站

- 自绘 SVG 棋盘（不依赖 chessgroundx / xiangqiground），90 个可聚焦落点
- 人机对弈，7 档难度（随机走子 → 特级大师 16 层）
- 实时分析面板（MultiPV 3）、提示箭头、悔棋、翻转、换边
- 键盘：方向键移动焦点、Enter 选子/落子、Esc 取消、`U`/`N`/`H`/`F` 快捷键
- 屏幕阅读器 live region、`aria-pressed`、可见焦点环
- 构建选择器（`?build=`）与只读测试钩子 `window.__pikafish`
- 基准页 `bench.html`：在真实浏览器里测三套构建，可导出 Markdown 表格

### 部署与工程

- Vercel：COOP/COEP/CORP + 严格 CSP + 引擎资源 `immutable` 缓存
- GitHub Pages：从源码构建 + `coi-serviceworker` 恢复隔离，文档挂在 `/docs/`
- 发布产物：三套 js/wasm + `SHA256SUMS` + `wasm-manifest.json` + `COPYING.txt`
- CI：lint、格式、类型、单测、构建、文档；WASM 构建；Chromium/Firefox/WebKit e2e
- 周基准任务，NPS 回归 >20% 告警
- 测试：44 个单元测试、20 个 Chromium e2e、Firefox/WebKit 冒烟

## 已知问题

- 长将之外的**长捉**未分类，按和棋处理（v0.2）
- 没有 iOS/Android 真机测试；建议移动端选 `single-simd`、Hash 16–32 MB
- 首次访问需下载约 48 MB 权重（之后走缓存）
- GitHub Pages 首次访问会因 Service Worker 接管而刷新一次
- 难度档位未经循环赛校准，相邻档位胜率单调性未验证

## 升级与兼容

- 三套构建都要求跨源隔离与 `SharedArrayBuffer`；单线程构建不是“无隔离”方案
- `engine.worker.js` 是 classic worker，需 `type: 'classic'`
- 权重必须与 `engine.json` 中固定的 SHA-256 一致；换网络需同时更新 `engine.json`
